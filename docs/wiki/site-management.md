# 站点管理

“站点管理”用于配置 Emby 主地址、对外入口、播放回源和流量策略。每个站点独立启停与统计。

![站点列表，虚构站点](https://raw.githubusercontent.com/snnabb/Meridian/v1.13.0/docs/images/sites.webp)

## 添加站点

打开“添加站点”，设置分为三个区域。

### 基本配置

| 字段 | 填写方式 |
| --- | --- |
| 站点名称 | 用于列表、日志和 Telegram，填写便于识别的名称。 |
| 入口模式 | 新建默认“路径”；其他模式见 [入口模式](ingress-modes.md)。 |
| 路径前缀 / 域名前缀 / 监听端口 | 根据所选入口显示，只填写对应字段。 |
| 主地址 | 原 Emby 的协议、域名或 IP、端口；允许已有基础路径，例如 `/emby`。 |
| 备用地址 | 可选，最多 7 条；默认按配置顺序参与故障切换。 |

新建主地址选择 HTTP 时默认 `8096`，HTTPS 时默认 `443`。粘贴完整 URL 会自动拆分协议、地址和端口；没有写端口的完整 HTTP URL 按标准 URL 的 `80` 处理，不自动改成 `8096`。

端口必须是 `1–65535` 的整数。小数、负数、科学计数法和超范围值不能保存。合法端口仍可能因权限、占用或防火墙而不可使用。

### 播放设置

选择“自动发现”“手动填写”或“直连播放”。不同模式只显示相关字段，不需要同时配置多套播放策略。详见 [播放模式](playback-modes.md)。

### 高级策略

按需配置 UA、真实客户端 IP、自定义 Header、缓存、流量额度和单连接限速。普通接入可先保留默认值，详见 [高级策略](advanced-settings.md)。

## 账号备忘录与数据迁移

从 v1.14.0 起，站点支持账号备忘、提前到期提醒、开号信息识别和数据导入导出。

在添加或编辑站点的“站点账号”模块保存账号名称、用户名、登录密码、安全密码、到期日期和备注。v1.14.1 起，网页、Telegram 和 CSV/TXT 导出的到期日统一显示为 `YYYY-MM-DD`；数据库、API 和 JSON 备份保留完整时间，编辑其他字段时也保留原始精度。一个站点可以有多个账号；账号名称和用户名至少填写一个，另一个自动补齐。密码会在账号列表和编辑框中直接显示，数据库仍使用加密存储。编辑时清空密码并保存，即可删除对应密码。

### 续期与提醒

v1.14.1 起，账号列表显示正常、即将到期和已到期状态；到期后仍可保留账号备忘。站点列表顶部可按即将到期、已到期、站点停用或未设置提醒筛选账号。选中已有账号的“续期”，可选一月（30 天）、一季度（90 天）、一年（365 天）或自定义 1–3650 天，在原到期日之后顺延；已过期或未设到期日期时从当前时间起算。每次续期会保留前后日期、天数和备注记录。

“提前提醒（天）”留空表示关闭，`0` 表示到期时提醒，`7` 表示提前七天提醒。需启用 Telegram Bot 管理并配置管理员，提醒会发到这些管理员的私聊；每个到期日期和提醒天数组合对每个管理员只提醒一次。提醒消息可标记“已处理”“忽略本次”或“明天再提醒”；选择延后后，到时间会再次提醒。站点列表的“提醒记录”保留每次发送尝试、失败原因和处理状态。重启后保留发送记录，续费后修改到期日期会重新计算提醒。提醒只含站点、账号名称和日期，不含密码。

没有写明时区的日期和时间按全局设置中的时区计算；只填日期表示当天 00:00，含 `Z` 或时区偏移的 ISO 时间按其自身时区计算。

### 草稿与导入导出

添加站点时可展开“从开号信息填充”。解析只填充可编辑表单，不会保存账号。先核对名称、入口、路径、主地址、备用地址及账号，在账号表单设置提前提醒，再点击“创建”一起保存。新站点内的“确认账号信息”只将该账号加入待保存列表，取消站点草稿不会写入数据库。创建时站点与账号在同一事务中保存，任一账号保存失败会整体撤销，表单仍保留供修改重试。只整理账号信息，不向 Emby 发起登录验证。

编辑已有站点时，账号表单只要有新增或修改，底部就会显示未保存提示并禁用站点“保存”。先点击“添加账号 / 保存账号”，或点击“放弃修改”，再保存站点；账号保存失败时保留输入并继续拦截，避免悄悄丢失。

自动识别可用 `站点名称：原神`、`名称：原神`，也支持独立的 `## 原神` 或 `**原神**` 标题；没有名称时采用服务器域名。默认路径根据服务器的主域名生成，例如 `https://yuanshen.help` → `/yuanshen/`，`https://emby.example.co.uk` → `/example/`，与自定义站点名称无关，保存前仍可修改。独立的多词标题也只作为名称；旧式 `**站点 用户名 密码**https://地址` 简写需要三项齐全且地址紧跟标题，推荐使用明确的字段式消息。

站点列表顶部的“导出”支持 JSON、CSV 和客户端 TXT，可以分别选择是否包含账号、是否包含登录密码和安全密码，默认不包含密码。没有账号的站点也会保留。客户端文本按站点、账号分组，单独标注原线路、备用线路和反代线路；可以选择原线路、反代线路或两者都有的多线路；JSON 用于站点配置和账号迁移，CSV 用于基本站点字段和账号的表格编辑。站点导出不包含全局设置、流量计数和固定上游请求头；整机配置迁移请使用备份与恢复。

导入与导出菜单支持鼠标悬停和点击：悬停打开的菜单在移出后收起，点击打开的菜单保持展开；再次点击按钮、点击外部或选择项目可关闭。键盘 Enter/Space 和触屏点击同样可用。

“导入”支持 JSON/CSV，最大 2 MB、500 个站点。先显示预览，再确认写入：

- 名称或主地址匹配已有站点时，默认跳过，可逐项或批量选择更新、另建站点。
- 更新按用户名匹配账号，未提供的密码保留，已有但未导入的账号保留；已有站点保留启停状态。
- 新站点默认停用；重复名称和路径会生成不冲突的名称与路径，实际结果显示在预览中。
- 错误行可跳过；预览后数据变化需重新确认。执行后逐项报告成功和失败，已成功的记录不会因其他记录失败而撤销。

以上账号、提醒和导入导出操作也支持 [Telegram Bot](telegram-bot.md)。

## 测试与启用

1. 运行“测试连接”，确认主地址与备用地址可达。
2. 保存站点，启用代理。
3. 复制站点访问地址，在客户端使用原 Emby 账户登录。
4. 验证媒体列表、视频播放、拖动进度与字幕。

连接检测不等于真实播放检测，尤其是主地址与媒体回源不同的站点。

## 修改与排序

第一阶段测试版中，名称、配额和限速可在运行中保存；单连接限速对新请求生效，站点总限速对现有连接也生效。入口、监听端口、回源、UA、缓存或播放策略变化需要重载代理，保存前会提示可能中断播放。预览后配置再次变化时，保存会被拒绝，需重新确认。

卡片上的“复制”打开新站点草稿：保留回源和通用策略，清空原入口、账号、请求头及动态域名规则，重新填写入口再创建。取消草稿不会写入数据库。“存为模板”保存可复用策略，模板不包含回源、入口或账号；模板保存在数据库中，随整机备份恢复，站点 JSON/CSV 导出不包含模板。

勾选卡片后点击“批量操作”，可启用、停用或修改额度/两种限速；留空保持原值，填 0 取消限制。先预览再执行，结果逐项显示，失败项不会撤销其他已成功的项。停用会断开所选站点的连接。

通过站点排序操作整理列表；顺序同时用于相关概览。站点的入口地址与上游主地址是不同字段，复制给客户端的是“访问地址”。

## 停用与删除

- 停用站点会停止其代理入口，配置仍可编辑。
- 删除前会要求确认。它删除的是 Meridian 站点配置，不会删除上游 Emby 的媒体文件。
- 要暂停访问而保留配置，使用停用，不必删除重建。

## 常见配置错误

| 错误 | 正确做法 |
| --- | --- |
| 客户端填写主地址 | 使用站点显示的 Meridian 访问地址。 |
| 把 `8096` 写成站点入口端口 | `8096` 通常是 Emby 回源端口，入口由所选模式决定。 |
| 复制路径入口时漏掉 `/cinema/` | 保留完整路径前缀。 |
| 使用面板管理员登录 Emby | 使用原 Emby 用户名与密码。 |
| 配置保存成功就认为可播放 | 还需验证网络、认证和实际媒体请求。 |
