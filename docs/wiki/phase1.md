# 第一阶段测试说明

本轮完善现有单管理员、单节点模式。正式版本仍为 v1.14.2；多用户、多节点和 Cloudflare Workers 部署尚未实现。

## 可体验的改进

1. 站点卡片显示本周期流量、剩余额度、下次重置、累计流量和计费方向。
2. 改名、配额和限速使用运行中更新。路由与代理策略修改仍会重启站点，保存前提示影响。
3. “站点总下载限速”让多条连接共享下载预算。它与单连接限速同时生效，直连或跳转到外部上游的媒体不计入。
4. 复制草稿、保存配置模板、批量启停/配额/限速。批量操作先预览、再确认、逐项反馈结果。
5. 正式/测试更新通道与配套回滚。仅签名测试 Release 可通过更新器安装，分支构建下载不等同于测试 Release。

## 更新通道与回滚

默认选择正式版。测试通道允许稳定版本及 `vX.Y.Z-beta.N` 预发布，按版本号选择最新已打包签名版本。切回正式通道不会直接降级；等待高于当前测试版的正式版，或恢复升级前快照。通道选择记在当前浏览器；CLI 每次以 `--channel` 明确指定。

支持该功能的标准 systemd 安装可使用：

```bash
sudo bash install.sh update --channel beta
sudo bash install.sh update --channel stable
sudo bash install.sh rollback
```

使用对应版本的安装器。旧更新代理未支持 v2 时，页面提示先运行配套安装器 `install -y` 刷新组件。不要在尚未发布时拿主支旧安装器替换测试版组件。

回滚将程序、数据目录和服务文件一起恢复到上次升级前。升级后的配置、账号及流量记录会被旧快照替换，操作前会另存当前数据。外部证书、Nginx 配置不在该快照中；数据库必须位于数据目录内。Docker 仍采用固定镜像标签与配套数据备份恢复。

签名测试 Release 的容器标签为 `beta` 及版本号，不覆盖正式 `latest`。本轮开发提交不自动创建 Release 或更新正式部署。

## 验证建议

使用独立数据目录及虚构上游，检查多条下载共享限速、修改配置时的连接表现、模板与批量操作。账号备忘录只存储信息，不向上游验证密码或自动模拟播放。
